# web/ — interfaz de exploración

Una pantalla: subir un video → palitos + toda la data. Los comandos y qué
esperar están en el `README.md` de la raíz del repo. El backend es `service/`.

```bash
pnpm dev     # http://localhost:3000 (necesita `.venv/bin/python -m service` en el 8765)
pnpm build   # chequeo de tipos + build de producción
pnpm lint
```
